# Module Author Guides

These guides help module authors address suggestions in the [check results](https://modules.magicmirror.builders/result.html):

- Set up a linter with [ESLint](eslint.md) or [Biome](biome.md).
- Improve README [installation](readme_bestpractices.md#installation-instructions), [update](readme_bestpractices.md#update-instructions), and [configuration](readme_bestpractices.md#config-instructions) instructions.

Suggestions and pull requests are welcome.
